# 🤖 LeRobot 统一控制界面 - 快速开始

## 简介

一个基于 Gradio 的 Web UI，将机器人推理工作流（部署、回放、相机预览）整合到一个直观的界面中。

## 特性

- **🚀 模型部署**: 部署 ACT、SmolVLA 或任何训练好的策略到真实机器人
- **🔄 数据集回放**: 回放 HuggingFace 数据集中的示教轨迹
- **📹 相机预览**: 实时相机画面可视化
- **⚙️ 统一配置**: 按类别组织的可折叠参数面板
- **💾 预设管理**: 保存、加载和分享配置预设
- **📊 实时日志**: 实时监控进程输出

## 安装

安装 UI 依赖：

```bash
# 使用 uv（推荐）
uv sync --extra ui

# 或使用 pip
pip install "gradio>=4.0.0,<6.0.0" "pyyaml>=6.0.0,<8.0.0"
```

## 快速启动

### 启动 UI

```bash
# 从仓库根目录
python workflows/robot_interaction/ui/launch.py

# 或使用 Python 模块语法
python -m workflows.robot_interaction.ui.launch
```

界面将在 **http://localhost:7860** 可用

### 基本工作流

1. **选择模式**: 选择 Deploy（部署）、Replay（回放）或 Camera Preview（相机预览）
2. **配置参数**: 在可折叠面板中调整设置
3. **可选：加载预设**: 选择保存的配置
4. **启动**: 点击 🚀 Launch 按钮
5. **监控**: 观察实时日志和状态
6. **停止**: 完成后点击 ⏹️ Stop

## 使用示例

### 部署 ACT 策略

1. 选择 **Deploy** 模式
2. **Policy Settings（策略设置）**:
   - Model Path（模型路径）: `outputs/train/act_v2/pretrained_model`
   - Device（设备）: `cuda`
3. **Robot Settings（机器人设置）**:
   - HTTP Base URL（HTTP 基础 URL）: `http://192.168.10.123:8010`
4. **Inference Settings（推理设置）**:
   - FPS: `30`
   - Strategy（策略）: `base`（仅推理，不录制）
   - Inference Type（推理类型）: `sync`
5. 点击 **🚀 Launch**

### 部署 SmolVLA 策略

1. 选择 **Deploy** 模式
2. **Policy Settings（策略设置）**:
   - Model Path（模型路径）: `outputs/train/smolvla/pretrained_model`
   - Device（设备）: `cuda`
3. **Robot Settings（机器人设置）**:
   - HTTP Base URL: `http://192.168.10.123:8010`
4. **Inference Settings（推理设置）**:
   - FPS: `30`
   - Strategy（策略）: `base`
   - Camera Rename Map（相机重命名映射）: `{"camera1": "image", "camera2": "wrist_image"}`
5. **Dataset Settings（数据集设置）**（展开面板）:
   - Repo ID: `username/my_dataset`
   - Task Description（任务描述）: `拿起红色方块放到蓝色碗里`
6. 点击 **🚀 Launch**

### 回放数据集轨迹

1. 选择 **Replay** 模式
2. **Dataset Settings（数据集设置）**:
   - Repo ID: `username/my_dataset`
   - Episode Index（轨迹索引）: `0`
   - FPS: `30`
3. **Robot Settings（机器人设置）**:
   - HTTP Base URL: `http://192.168.10.123:8010`
4. 点击 **🚀 Launch**

### 预览相机画面

1. 选择 **Camera Preview** 模式
2. **Camera Settings（相机设置）**:
   - 选择要显示的相机: `camera1`, `camera2`, `camera3`, `camera4`
   - FPS: `30`
   - Quad Layout（四宫格布局）: ✓ (2x2 网格)
3. **Robot Settings（机器人设置）**:
   - HTTP Base URL: `http://192.168.10.123:8010`
4. 点击 **🚀 Launch**

## 配置预设

### 加载预设

点击 **Load Preset（加载预设）** 下拉菜单并选择：
- `deploy_act_default` - 标准 ACT 部署
- `deploy_smolvla_default` - 带任务描述的 SmolVLA
- `replay_default` - 数据集回放配置

### 保存自定义预设

1. 按需配置所有参数
2. 点击 **💾 Save Preset（保存预设）**
3. 输入预设名称（例如 `my_act_config`）
4. 预设将保存到 `workflows/robot_interaction/ui/presets/`

## 参数说明

### 推理策略说明

- **base**: 仅推理，不录制（最常用）
- **sentry**: 持续录制，保存所有数据
- **highlight**: 环形缓冲，按键触发保存片段
- **dagger**: 人工干预模式，可随时接管控制
- **episodic**: 分段录制，每个 episode 单独保存

### 推理类型说明

- **sync**: 同步模式 - 推理完整 chunk，执行所有动作后再重新推理（稳定，响应较慢）
- **rtc**: Real-Time Chunking（实时分块）- 执行前 N 步的同时推理下一个 chunk（响应更快）

### VLA 任务描述

视觉-语言-动作模型需要任务描述：

```yaml
dataset:
  single_task: "拿起红色方块放到蓝色碗里"
```

任务描述会被 tokenize 并在推理时作为条件输入策略。

## 常见问题

**Q: UI 无法启动？**  
A: 检查依赖安装：`pip list | grep gradio`，重新安装：`pip install --upgrade "gradio>=4.0.0"`

**Q: 进程启动失败？**  
A: 
1. 查看 **Process Logs（进程日志）** 面板
2. 验证机器人 HTTP 端点可访问: `curl http://192.168.10.123:8010/state`
3. 确保模型路径存在且包含 `config.json`

**Q: VLA 模型提示需要任务描述？**  
A: 展开 **Dataset Settings（数据集设置）** 面板并填写 **Task Description（任务描述）**。

**Q: 可以同时使用 CLI 和 UI 吗？**  
A: 可以！UI 只是对现有脚本的封装，两者可以交替使用。

**Q: 如何从另一台电脑访问 UI？**  
A: UI 默认监听 `0.0.0.0`，可通过 `http://<机器人电脑IP>:7860` 访问。

```
    └── replay_default.yaml
```
